# 오호민 · AI 연구 및 개발

석사 과정에서는 무선 센서 네트워크의 클러스터 헤드 선택 문제를 연구했습니다. 팀 프로젝트 GrowPath에서는 Qwen LoRA 실험과 PostgreSQL 자료 관리, 로드맵 생성 백엔드를 다뤘습니다.

## 포트폴리오와 SKN AI 캠프

- 연구와 팀 프로젝트를 정리한 [SKN 포트폴리오](https://github.com/SKN-Project/Portfolio) · [포트폴리오 PDF](https://github.com/SKN-Project/Portfolio/blob/main/%ED%8F%AC%ED%8A%B8%ED%8F%B4%EB%A6%AC%EC%98%A4.pdf)
- 실습과 팀 프로젝트를 모아 둔 [SKN-Project 조직](https://github.com/SKN-Project) · [전체 저장소 목록](https://github.com/orgs/SKN-Project/repositories)
